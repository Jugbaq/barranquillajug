En nuestra sesión de octubre 2026, conectamos dos mundos: Kotlin en el backend y Flutter en el mobile. Desde BarranquillaJUG desarrollamos y desplegamos una API en Kotlin que fue consumida en vivo desde una aplicación Flutter — demostrando cómo el ecosistema JVM se integra sin problema con tecnologías completamente diferentes.

📅 **28 de Octubre de 2026 – 6:00 PM**
📍 **Universidad Autónoma del Caribe** – Cl. 90 #46-112, Riomar, Barranquilla, Colombia

🎟️ **[Regístrate aquí](https://luma.com/8hd2rlbv)**

###### Descubriendo Flutter: Creando Experiencias Móviles Multiplataforma

¿Cómo se construye una aplicación móvil moderna? En esta charla exploramos el potencial de Flutter a través de una aplicación real y funcional, y entendemos cómo se comunica con una API externa en Kotlin.

**Jorge Palacio** – Senior Frontend Developer 🇨🇴

---

###### Temas cubiertos

- Fundamentos de Flutter para el desarrollo móvil multiplataforma
- Construcción de una aplicación móvil real con Flutter
- Integración de Flutter con una API REST desarrollada en Kotlin
- Cómo el ecosistema JVM se comunica con tecnologías externas
- Casos prácticos de aplicaciones modernas con backend JVM y frontend Flutter

Un evento presencial con la comunidad Java de Barranquilla, patrocinado por **BAQJUG**, **Universidad Autónoma del Caribe**, **DevJVM**, **Giniem**, **CaribeDev** e **IEEE Computer Society UAC**.
