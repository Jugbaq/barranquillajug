¿Qué es mito y qué es realidad en el ecosistema actual de Java? En esta sesión repasamos seis afirmaciones que se dicen habitualmente sobre Java y las contrastamos con fuentes oficiales. Algunas son mito. Otras, no tanto. Descubre cómo las últimas actualizaciones de la plataforma están cambiando la forma en que construimos software.

📅 **15 de Octubre de 2026 – 6:30 PM GMT-5**
🖥️ **Evento Virtual**

▶️ **[Ver en YouTube](https://www.youtube.com/watch?v=1uXqW4OATvA)**

---

###### Speaker

**Jordy Rodriguez** 🇨🇴 – Arquitecto de Software y Oracle ACE

---

###### Los seis mitos que exploramos

**¿Java es verboso?**
¿Sigue siendo cierto con records, sealed classes y pattern matching en las versiones modernas?

**¿Kotlin ya reemplazó a Java?**
La coexistencia real entre ambos lenguajes en el ecosistema JVM.

**¿Java es lento y consume demasiada memoria?**
Qué dicen los benchmarks actuales y cómo GraalVM y Project Loom cambian la ecuación.

**¿Concurrencia moderna = programación reactiva?**
Virtual Threads vs Reactive: cuándo usar cada uno y qué dice la plataforma.

**¿Para hacer IA tienes que irte a Python?**
El estado real de Spring AI, LangChain4j y el ecosistema Java para IA generativa.

**¿Java no sirve para scripts?**
JBang y las nuevas capacidades de scripting en el ecosistema Java.

---

###### Temas cubiertos

- Java moderno: records, sealed classes, pattern matching y más
- Coexistencia de Java y Kotlin en la JVM
- Performance real de Java: GraalVM y Project Loom
- Virtual Threads vs programación reactiva
- IA con Java: Spring AI y LangChain4j
- Scripting con JBang en el ecosistema Java
