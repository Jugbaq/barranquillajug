En nuestra sesión virtual del 30 de julio 2026, Victor Orozco nos guió por el estado del arte de las prácticas de seguridad de información, DevOps y Java. Con un ejemplo de extremo a extremo, exploramos cómo herramientas clásicas y modernas construyen mejores pipelines para el ciclo de desarrollo y entrega continua.

📅 **30 de Julio de 2026 – 6:00 PM GMT-5**
🖥️ **Evento Virtual**

▶️ **[Ver en YouTube](https://www.youtube.com/watch?v=XwY05hfHnlQ)**

---

###### Sobre la charla

Con un ejemplo E2E analizamos de principio a fin cómo prácticas como Infrastructure as Code (IaC), análisis estático de código e IA nos ayudan a producir código seguro en la era de los LLMs. La sesión mostró cómo herramientas "viejas" y nuevas se combinan para construir mejores Harnesses dentro del ciclo de desarrollo y entrega continua con Java.

###### Temas cubiertos

- Estado del arte de las prácticas de seguridad en el ecosistema Java
- DevSecOps: integrando seguridad en el ciclo de desarrollo

- Análisis estático de código como práctica de seguridad
- IA para producir código seguro en la era de los LLMs
- Ejemplo E2E: del código al despliegue seguro con Java
